> **Oqila AI Platform** · Экосистема цифровизации женского предпринимательства в Узбекистане

Карманный AI бизнес-ассистент для женщин-предпринимательниц, ремесленниц и микробизнеса. Автоматизирует упаковку товаров, копирайтинг, финансовые расчёты и базовый юридический комплаенс.

## 🚀 1. Локальный запуск (для тестирования)

```bash
# 1. Перейти в папку проекта
cd oqila-ai

# 2. Установить зависимости Python
pip install -r requirements.txt

# 3. (Опционально) Пересобрать React-фронтенд (dist уже собран):
# cd frontend && npm install && npm run build && cd ..

# 4. Запустить сервер
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

Откройте в браузере: **http://localhost:8000** (откроется современный React SPA интерфейс)

## ☁️ 2. Развёртывание на VDS (Ubuntu / Debian)

Мы подготовили автоматический скрипт развёртывания `deploy.sh`:

```bash
# На вашем сервере VDS:
git clone <ваш_репозиторий>
cd oqila-ai

# Сделать скрипт исполняемым и запустить
chmod +x deploy.sh
./deploy.sh
```

### Что делает `deploy.sh`:
1. Устанавливает `python3`, `venv`, `nginx`, `git`, `curl`.
2. Создаёт виртуальное окружение и ставит зависимости из `requirements.txt`.
3. Создаёт и запускает фоновый сервис **systemd** (`oqila-ai.service`), который автоматически перезапускается при падении и при перезагрузке сервера.
4. Проверяет health check.

### Настройка HTTPS для Telegram Mini App (Nginx + Let's Encrypt):
Telegram требует HTTPS для Web App URL. Настройте Nginx за 2 минуты:

```bash
# 1. Скопировать конфиг Nginx
sudo cp nginx.conf /etc/nginx/sites-available/oqila-ai

# 2. Укажите ваш домен внутри файла:
sudo nano /etc/nginx/sites-available/oqila-ai

# 3. Активировать сайт и перезагрузить Nginx
sudo ln -s /etc/nginx/sites-available/oqila-ai /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx

# 4. Выпустить бесплатный SSL-сертификат:
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d your-domain.com
```

### Привязка Telegram Webhook:
Если в `.env` задан `WEBAPP_URL`, вебхук регистрируется автоматически при старте сервера.
Вручную (только для администратора, ключ из `ADMIN_SECRET_KEY`):
```bash
curl -X POST "https://your-domain.com/api/set-webhook" -H "Content-Type: application/json" -H "X-Admin-Key: $ADMIN_SECRET_KEY" -d '{"url":"https://your-domain.com"}'
```
Каждое обновление от Telegram проверяется по секрету `X-Telegram-Bot-Api-Secret-Token`.

## 🔑 Переменные окружения (.env)

```env
GEMINI_API_KEY=your_gemini_api_key_here
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
AI_MODE=gemini
WEBAPP_URL=https://your-domain.com   # (укажите при деплое на VDS)
ADMIN_SECRET_KEY=...                 # ключ админ-панели, минимум 16 символов
SESSION_SECRET=...                   # подпись сессий пользователей
TELEGRAM_WEBHOOK_SECRET=...          # секрет вебхука Telegram
ADMIN_TELEGRAM_IDS=123456789         # Telegram id администраторов (вход в /admin без ключа)
ALLOW_GUEST_LOGIN=1                  # 0 — пускать только из Telegram
GUESTS_PER_IP_PER_HOUR=5             # сколько новых гостей в час можно создать с одного IP (0 — без лимита)
UZUM_KEY_ENCRYPTION_KEY=...          # ключ Fernet для шифрования API-ключей Uzum в базе
GEMINI_TEXT_MODEL=gemini-2.5-flash   # текстовая модель; GEMINI_TEXT_FALLBACK_MODEL — запасная
GEMINI_LEGAL_MODEL=                  # модель юриста (пусто — текстовая)
HOST=0.0.0.0
PORT=8000
```
`deploy.sh` сам генерирует `ADMIN_SECRET_KEY`, `SESSION_SECRET` и `TELEGRAM_WEBHOOK_SECRET`, если они пустые.
Полный список — в `.env.example`.

## 🎤 Подготовка к выступлению

**Экран для сцены — `https://your-domain.com/stage`.** Крупные живые цифры (карточки, пользователи, расчёты,
вопросы юристу), график за 14 дней и QR-код бота, чтобы зрители сразу открыли его на своих телефонах.
Обновляется каждые 10 секунд; язык переключается кнопками UZ/RU или `?lang=ru`.
Показываются только реальные действия: демо-аккаунты и карточки с кнопки «Быстрое демо» не учитываются.

**Демо-аккаунт без пустого экрана.** Заполните свой аккаунт примерами карточек и демо-магазином Uzum:
```bash
python scripts/seed_demo.py --tg-id <ваш Telegram id> --lang uz --reset
```
Свой id можно узнать у @userinfobot. Аккаунт помечается как демо, поэтому его данные не попадают на `/stage`.

**Чек-лист перед выходом на сцену**
- Прогоните сценарий целиком с `AI_MODE=mock` (без интернета всё должно работать).
- Кнопка «✨ Быстрое демо» всегда отвечает мгновенно и не тратит квоту Gemini.
- Этикетки Uzum содержат настоящий штрихкод Code 128 — его можно отсканировать телефоном.
- Запишите видео демо на случай проблем с сетью.

## ⏱️ Лимиты ИИ

Чтобы квоту Gemini нельзя было исчерпать (например, толпой на фестивале):
- **на пользователя:** 20 карточек в час / 60 в день, 30 вопросов юристу в час / 100 в день — затем ответ 429 с понятным
  сообщением. Место в лимите занимается *до* вызова ИИ одной транзакцией (таблица `ai_reservations`), поэтому
  параллельные запросы лимит не обходят. Неудачная генерация лимит не расходует, но число попыток ограничено
  втрое большим порогом. Фото, отправленное боту, расходует тот же лимит. Остаток — `GET /api/limits`;
- **на всё приложение:** `AI_GLOBAL_DAILY_LIMIT` реальных запросов к Gemini в сутки (таблица `ai_calls`; одна карточка —
  до 7 запросов). После этого ИИ честно отвечает «временно недоступен»: образец текста показывается с пометкой
  и **не сохраняется** в историю;
- **гости:** не больше `GUESTS_PER_IP_PER_HOUR` (5) новых гостевых аккаунтов в час с одного IP, плюс `limit_req`
  на `/api/auth/login` в nginx. `ALLOW_GUEST_LOGIN=0` полностью отключает вход вне Telegram.

Все лимиты настраиваются в `.env` (см. `.env.example`).

## 🎨 Фото, плакаты и акции

В студии пользователь выбирает, что хочет получить:

| Тип | Что получится | Варианты |
|---|---|---|
| **Фото товара** | сцена вокруг товара | 13 стилей: студия, Восток, Uzum, Luxury, природа, вид сверху, в руках, подарок, Навруз, 8 Марта, дастархан, на модели, коллаж из 3 ракурсов |
| **Плакат** | товар + название, цена, преимущества, контакты | Витрина, Журнальный, Минимал |
| **Акция** | бейдж скидки, старая и новая цена, срок | Скидка, Новинка, Ограниченный тираж |
| **Для Uzum** | инфографика с выносками | Выноски |
| **Сторис** | вертикальная 9:16 с кнопкой «Заказать» | Сторис |

**Как это устроено.** ИИ рисует только картинку (товар в красивой сцене и свободное место под текст). Весь текст — название, цену,
преимущества, контакты — накладывает сервер (`services/poster.py`, шрифт Inter из `assets/fonts/`, лицензия OFL).
Поэтому цифры и узбекские буквы (`o'`, `g'`) всегда точные, а текст можно править без нового вызова ИИ и без траты лимита.
Форматы кадра: 1:1, 4:5, 3:4, 9:16. Без ключа Gemini (`AI_MODE=mock`) плакат собирается из фото пользователя, так что
демо работает и офлайн.

**Брендинг.** Название магазина, контакты, фирменный цвет и логотип пользователь задаёт один раз (блок «Мой бренд»
в редакторе плаката): они сами появляются на всех новых плакатах. Логотип проходит проверку (PNG/JPG/WEBP до 2 МБ).

Все стили описаны в одном месте — `services/presets.py`; фронтенд получает их из `GET /api/photoshoot-presets`,
поэтому новый стиль добавляется одной записью. Ограничение правок плаката: `POSTER_RENDER_LIMIT_PER_HOUR` (по умолчанию 400).

## 🖼️ Хранение фото

Фото студийной съёмки сохраняются файлами в `media/cards/`, в базе хранится только ссылка.

## 🔒 Безопасность

- **Вход.** В Telegram пользователь определяется только по подписанному `initData` (проверка HMAC и срока давности).
  В обычном браузере сервер создаёт гостевой аккаунт. После входа выдаётся подписанный токен сессии,
  и все пользовательские API берут `user_id` из него, а не из запроса.
- **Изоляция данных.** История карточек, фото, профиль и все данные Uzum (ключ API, магазины, заказы,
  остатки, уведомления) хранятся отдельно для каждого пользователя.
- **Админ-панель** (`/admin`): заголовок `X-Admin-Key` с `ADMIN_SECRET_KEY` или Telegram-аккаунт
  администратора: `ADMIN_TELEGRAM_IDS` или флаг, который ставится в админ-панели. `/admin <ключ>` в боте даёт
  только сессию на 1 час и ничего не пишет в базу. Ключ никогда не передаётся в URL.
  Без `ADMIN_SECRET_KEY` вход по ключу отключён.
- **Картинки и скачивание.** Токен сессии (30 дней) в адресах не используется: ссылки для `<img>` и скачивания несут
  10-минутный media-токен (`POST /api/media-token`, параметр `?mt=`).
- **Ключи Uzum API** хранятся в базе зашифрованными (Fernet, `UZUM_KEY_ENCRYPTION_KEY`); старые записи шифруются при старте.
- **Загрузки.** Не больше 10 МБ и 40 мегапикселей, тип определяется по содержимому файла (JPG, PNG, WEBP).
- Uvicorn слушает только `127.0.0.1`, наружу сервис открыт через nginx с HTTPS.

## Фото для Uzum и инфо-карточки

Два основных формата студии (плакаты, акции, сторис и сцены — в «Ещё форматы»):

- **Фото для Uzum** — чистое фото 3:4, 1080×1440, JPEG до 5 МБ. «Белый фон» убирает фон только вокруг товара
  (заливка от краёв кадра), «Светлый градиент» оставляет мягкий серый фон.
- **Инфо-карточка** — ИИ рисует карточку в одном из 8 шаблонов (белая с характеристиками, тёмная,
  плашки, выноски, таблица и др.) с вашим товаром. После рисования второй вызов ИИ **читает текст обратно**
  и сравнивает с заданным; до 3 попыток, статус «проверено / есть расхождения» показан в интерфейсе.
  Текст можно поправить и перерисовать, а «точная версия» (плакат, рисуется сервером) всегда без опечаток.

Правдивость: размеры, вес и материал берутся только из строк продавца («Название: значение»); подсказки ИИ
(слоган, плашка, «для чего») — на проверку продавцу, обещания вроде «премиум», «гарантия», «№1» отфильтровываются.
ИИ слегка перерисовывает узор товара — сравнивайте с оригиналом перед публикацией.

Модели: `GEMINI_IMAGE_MODEL` (по умолчанию `gemini-3.1-flash-image`), `GEMINI_IMAGE_FALLBACK_MODEL`,
`GEMINI_VERIFY_MODEL`. Ключ хранится только в окружении, не в репозитории.
