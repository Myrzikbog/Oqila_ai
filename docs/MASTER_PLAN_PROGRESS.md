## Решения, принятые по ходу (войдут в итоговый отчёт)

- Все «решения владельца» пока приняты по умолчанию из плана.
- 1.4 / 1.5: если текстовая модель упала, а фото готово — карточка сохраняется с пустым описанием и пометкой
  `ai_fallback_scope: "text"` (образец текста рядом с настоящим фото не подставляется).
- 1.9: демо-заказы Uzum больше не дают пуш «новый заказ» (раньше давали; тест переписан).
- 1.9: для шифрования ключей Uzum добавлена зависимость `cryptography`; если `UZUM_KEY_ENCRYPTION_KEY` не задан,
  ключ создаётся в файле `.uzum_key` (его нельзя терять и нельзя класть в бэкап базы).
- 1.3: `AI_GLOBAL_DAILY_LIMIT` теперь считает запросы к Gemini, а не генерации (одна карточка — до 7 запросов);
  значение по умолчанию 1000 оставлено, то есть бюджет стал строже в несколько раз.
- 2.8: старый рендер плакатов не удалён совсем, а перенесён в `scripts/` — иначе миграция из `deploy.sh`
  не смогла бы «запечь» плакаты после обновления кода. Приложение его не импортирует (есть тест-страж).
- 2.3: 4:5 запрашивается у модели как 4:5 (`GEMINI_IMAGE_4_5=0` включает вырезание из 3:4). По актуальной
  документации Gemini это не сверялось.
- Тесты: `tests/test_poster.py` удалён вместе с кодом (как разрешает п. 0.5); несколько старых тестов переписаны
  под новое поведение (mock не сохраняется, токен сессии в URL не принимается).
